LOCATION & FORECAST

Weather and calendar

Weather measurement

Archived runs use a conservative 12-hour publication buffer. Issued-forecast scores measure real operation. Weather-model disagreement widens solar scenarios; it is not a calibrated probability range.

Update intervals

History weighting and model updates

One-year half-life gives year-old examples half the weight. The replay percentage controls the number of older examples; age weighting further reduces their influence. Fine tuning mixes recent data with older seasonal examples. Candidates must improve independent overnight forecasts; validation is never age-weighted.

SOLAR ARRAY

Your panel banks

Use one bank for each panel orientation. Select individual string sensors for differently oriented arrays, or one aggregate PV sensor when all panels face the same way. Do not include both strings and their aggregate. Azimuth is clockwise from north: north 0°, east 90°, south 180°, west 270°. Capacity is inferred during training.

KNOWN HOME LOADS

Appliances and schedules

Use HA state for runs already active, or enter recurring local-clock schedules. Minimum total load avoids adding an appliance twice when the CNN already expects it. Extra load is for runs outside the normal pattern. Leave start and end equal for live-state only.
